# <img width='24' src="./src/main/resources/icon.png"> More Beehive Variants
> ![Mod Icon](https://raw.githubusercontent.com/pnk2u/resources/main/ModProjects/More-Beehive-Variants/pres/logo/logo_c.png)
>
> A simple mod adding wood variants for Minecraft's Beehive Block.

### Compatibility

- Minecraft: `1.20.1`, `1.21(.1)`, `1.21.4`~`1.21.10`
- Mod Loader: _Fabric_
- Requires: [`Fabric API`](https://modrinth.com/mod/fabric-api)

### ᴬ⃯ ᵦ⃔ Translations

Currently available in:
- English
- German
- Ukrainian (@[StarmanMine142](/../../../../StarmanMine142) with [PR #2](../../pull/2), added in [`1.7.4`](/../../#174))

Want to help translate? Feel free to open a PR to the **default branch (`1.21(.1)`)**.
